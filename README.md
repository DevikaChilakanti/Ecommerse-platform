# Ecommerse Platform

A full-stack e-commerce platform built using modern web technologies.

## Project Structure

- `apps/web` - apps/web - Customer-facing website and admin dashboard
- `apps/api` - Backend REST API
- `packages/types` - Shared TypeScript types
- `packages/ui` - Shared UI components
- `packages/config` - Shared configuration
- `infrastructure` - Infrastructure and deployment configuration
- `docs` - Project documentation
- `tests` - Cross-application tests

## Development Approach

This project follows an industry-style software development process:

1. Requirements
2. Architecture
3. Development
4. Testing
5. Code Review
6. Security Review
7. CI/CD
8. Deployment

## AI-Assisted Development

AI tools will be used as development assistants for:

- Requirements analysis
- Architecture review
- Code generation
- Code review
- Test generation
- Debugging
- Documentation

AI-generated code will be reviewed and tested before being accepted.
